# Restore & Uncover - Technical Demo

## Descripción

Restore & Uncover es un juego de simulación y puzles disponible para PC en el que el jugador toma el papel de un especialista en restauración de propiedades. 

El objetivo es limpiar, reparar y restaurar diferentes lugares abandonados mientras se recolectan materiales, se fabrican herramientas y se resuelven puzles para descubrir los secretos de cada espacio

## Características Principales

- Sistema de limpieza de superficies mediante máscaras de textura y Shader Graph.
- Sistema de inventario y herramientas equipables.
- Recolección de materiales reciclables.
- Sistema de fabricación mediante planos.
- Puzles interactivos mediante raycasting.
- Sistema eléctrico e interacción con objetos.
- Sistema de guardado y persistencia del progreso.
- Configuración de niveles mediante ScriptableObjects.

## Características técnicas

- **Motor:** Unity 6000.3.10f1.
- **Lenguaje:** C#
- **Render Pipeline:** Universal Render Pipeline (URP)
- **Shaders:** Shader Graph
- **Persistencia:** JSON y almacenamiento de máscaras de limpieza
- **Arquitectura:** ScriptableObjects, eventos, interfaces y herencia
- **Control de versiones:** Git + Git LFS para assets de audio grandes

## Estado del proyecto

Actualmente el proyecto se encuentra en desarrollo como demo técnica. Las mecánicas principales de interacción, limpieza, inventario, fabricación, puzles y persistencia ya están implementadas.
