# Restore & Uncover - Unity Techical Demo

## Descripción
En este juego de simulación y puzle, disponible para PC, los jugadores tomarán el papel de un especialista en restauración de propiedades, cuya misión es limpiar, reparar y restaurar diversos lugares abandonados. A través de la recolección de chatarra para fabricar herramientas y la resolución de puzles, el jugador deberá descubrir los secretos de cada espacio, transformando el caos en orden y revelando las historias ocultas de cada lugar. El objetivo es completar cada nivel de manera eficiente, optimizando recursos y tiempo, para ganar recompensas que permitan seguir expandiendo las operaciones de limpieza y restauración.

## Características Técnicas
* **Motor:** Unity 6000.2.14f1.
* **Lenguaje:** C#.
* **Mecánicas implementadas:** Sistema de inventario, detección de colisiones, Raycasting para interacción, sistema de limpieza, sistema de fabricación, sistema de iluminación.
* **Render Pipeline:** URP y uso de Shader Graph para efectos visuales.
